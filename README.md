# Orbit

**An interactive 3D map of the universe, from the ISS to the edge of the observable universe.**

A ByteForge Studios app.

## Download

**[Download Orbit for Windows](https://github.com/azaan-ship-it/Orbit/releases/latest/download/Orbit-Setup-1.0.exe)**

Or grab it from the [Releases](https://github.com/azaan-ship-it/Orbit/releases) page. Windows may show a SmartScreen warning because the app isn't signed yet: click **More info → Run anyway**.

## Use it on the web

**[Open Orbit in your browser](https://byteforge-orbit.web.app)**, no install needed.

## Features

- Live Earth with about 1,000 real satellites and the ISS, tracked from CelesTrak
- The solar system live: planets, moons, dwarf planets, comets and 353 real asteroids
- 109,000 real stars, constellations and about 5,000 exoplanets you can fly into
- Nebulae, black holes, the Milky Way, galaxies, the cosmic web and dark matter
- History mode: the story of the universe from the Big Bang onward
- WASD flying, time controls and search for anything
